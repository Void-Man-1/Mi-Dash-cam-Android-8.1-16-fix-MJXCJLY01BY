User manual summary

This is an offline English reference for the original Mi Dash Cam MJXCJLY01BY. The complete illustrated manuals are bundled above.

Normal use

  1. Install a Class 10 or faster 8–64 GB microSD/TF card.
  2. Connect the camera to the supplied 5 V / 2 A car power adapter.
  3. Use the camera's capacitive buttons and 3-inch display to check its status and aim.
  4. For phone access, enable the camera's Wi-Fi, join it from the phone, and return to this app.

The app can show the live picture, browse historical recordings, play them from the camera, and download selected video to the phone without using mobile-data traffic.

Emergency recordings

The built-in adjustable G-sensor can protect an emergency recording so that ordinary cyclic recording does not overwrite it. Preserve important evidence by exporting it to another device as soon as practical.
