Connect to camera Wi-Fi

  1. Power on the Mi Dash Cam and enable Wi-Fi on the camera.
  2. Open Android Settings → Wi-Fi.
  3. Select the dash cam's network and enter its password if Android asks for it.
  4. When Android says the network has no internet, choose to remain connected.
  5. Return to Mi Dash Cam. Keep this Wi-Fi connection active while viewing or transferring video.
No internet is normal: the app talks directly to the dash cam through the Wi-Fi gateway. Internet is only needed for Xiaomi account sign-in and other online services.

If Android switches away

Reconnect manually, pause VPN software that overrides local routing if necessary, and temporarily disable automatic switching to mobile data or a different saved Wi-Fi network.

Connection flow verified from the recovered Mi Dash Cam APK and tested on Android 15 and Android 16. Camera-side pairing still requires physical MJXCJLY01BY hardware.
